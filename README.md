
## Edamam API Setup

To use the Edamam Recipe Search API, add the following to your `.env` file in the project root:

```
VITE_EDAMAM_APP_ID=your_edamam_app_id_here
VITE_EDAMAM_APP_KEY=your_edamam_app_key_here
```

Replace the values with your actual Edamam credentials. Restart the dev server after updating the `.env` file.
